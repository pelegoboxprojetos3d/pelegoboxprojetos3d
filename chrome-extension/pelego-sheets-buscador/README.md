# PELEGO BOX • Buscador Sheets

Extensão local do Chrome para a planilha SITE.

Comportamento:
- Ao entrar em `Dashboard_Mensal` ou `Dashboard_Anual`, o Apps Script fecha o buscador.
- Ao voltar para `Videos_projetos`, esta extensão abre novamente `🔎 BUSCADOR > Abrir buscador` automaticamente.

## Instalação
1. Atualize o repositório local com `git pull`.
2. Abra `chrome://extensions`.
3. Ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Escolha a pasta `chrome-extension/pelego-sheets-buscador`.
6. Recarregue a planilha SITE.
